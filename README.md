# Contents:
- `pka_results/`: contains results for compounds used in training of the ML model
- `pka_results_test/`: results obtained for latest set of test compounds
- `results_analysis/`: historic record of results obtained through various test rounds ; after each test round the test compounds were added to the training data
- `test_set/`: input files for the test compounds
- `training_set/`: input files for the training compounds
- `pka_gpr_calibrate.py`: python code to run the required calculations and train the model ; has two modes of running
  1. `--train`: used to train the model on the compounds defined in `training_set/`
  2. `--predict`: used to test the model/predict pKa of novel compounds

see `submit_test.sh` and `submit_training.sh` on how to use the script
